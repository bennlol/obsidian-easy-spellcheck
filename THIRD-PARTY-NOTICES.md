## Downloaded dictionaries

No language dictionary is bundled with the plugin. The optional downloader retrieves selected files from a pinned revision of wooorm's normalized dictionaries collection. The collection tooling is MIT licensed, but every downloaded language retains its original copyright and license. The plugin stores the upstream license file when one is available. For Estonian and Basque, whose upstream packages declare a license without a separate license file, it stores the declared license identifier and source link. The confirmation dialog links to the upstream source before downloading.
